# Nim

- _Efficient, Expressive, Elegant_
- Uses uniform function call syntax
- Indentation is part of the syntax

## Applications

- Web Applications
- System Programming
- Embedded Systems

## Hello World

```Nim
echo "hello world"
echo("hello world")
"hello world".echo()
"hello world".echo
echo("hello", " world")
"hello".echo(" world")
"hello".echo " world"
```
