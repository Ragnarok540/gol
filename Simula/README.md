# Simula

- _The First Object-Oriented Programming Language_
- Introduced classes, objects, inheritance, coroutines and featured garbage collection.

## Applications

- Discrete Event Simulation
- Simulation of VLSI Design
- Process Model Simulation
- Communication Protocol Simulation
